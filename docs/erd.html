Entity Relationship & Data Model

Three tables carry the whole system. The design's most important property is a deliberate absence: there is no foreign key from transactions to status_map, so an unmapped status can still be ingested — and then be counted, loudly, as unclassified rather than silently dropped or silently treated as revenue.

Load-bearing rule Ingestion stores raw_status verbatim and never interprets it. Meaning is assigned only at read time, by joining transactions → status_map. That single seam is what lets a new source or a new status value arrive without touching the metric.

The canonical vocabulary

Five canonical statuses, enforced by a CHECK on status_map.canonical. Only one — collected — is in the allow-list that counts as revenue.

collected in allow-list

Money is actually collected. The single value in COLLECTED_STATUSES.

pending

Authorized / awaiting capture / draft. Not revenue.

failed

Declined, errored, written off.

refunded

Money returned. Leaves the collected set by exclusion.

voided

Cancelled before capture.

Why no foreign key (the point of the whole design)

Deliberate omission If transactions.raw_status had a FK into status_map, an unmapped status from a new source would cause the insert to fail — pushing the failure to ingest time and, under pressure, tempting a “just skip it” patch that silently drops revenue.

Instead, unmapped rows insert freely and are surfaced two ways at read time:

  • The collected_revenue() function uses an inner join to status_map, so an unmapped status structurally cannot be counted — this is the allow-list expressed as data topology.
  • A separate unclassified query (a left join with a null check) counts and lists every (source, raw_status) with no mapping, and both endpoints return it. Fail closed, report loudly.

This is also what the E5-S2 mapping-coverage tripwire guards: a CI test asserts select (source, raw_status) from transactions except select (source, raw_status) from status_map returns zero rows, so a new vocabulary breaks the build instead of quietly under-reporting.
